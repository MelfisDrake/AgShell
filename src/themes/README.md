# Themes

`ghostty/` is the Ghostty theme set of [iTerm2-Color-Schemes](https://github.com/mbadolato/iTerm2-Color-Schemes)
(MIT, see `LICENSE-iTerm2-Color-Schemes`), the set agterm ships, taken at commit
`c379d7a31af861838a017468b03120c8970eaa00` (2026-10-16). `agshell` is AgShell's own default theme. The build copies both
into `themes\` next to `agshell.exe`; user themes go to `%APPDATA%\agshell\themes` and win over bundled ones by name.
