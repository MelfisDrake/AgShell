# Границы исходного снимка

Этот репозиторий начинает отдельную историю Git. В него включены продуктовые исходники,
тесты, темы, сборочные скрипты, лицензии, пользовательские документы и архитектурные решения.
Частные журналы работы, память менеджера проекта, снимки экранов, сырые результаты проверок,
старые downloads и история прежнего репозитория в него не входят.

Реализация следует модели agterm e0b48445ad0a59c7e767b3eb54be1a31d258c3e2;
Windows использует WPF/WebView2/ConPTY вместо AppKit/WebKit. Сохранённые ADR описывают причины.
Ссылки на частные доказательства заменены этим описанием пределов, а не заявлением
о сертификации или переносом закрытых результатов в публичную историю.

Штатные проверки: `dotnet build agshell.slnx`, `dotnet test agshell.slnx`, frontend tests.
Адресный native bridge test использует отдельные временные файлы и профиль WebView2;
для него нужны Windows, WebView2 Runtime и доступный desktop. Он не запускает основную
установку и не вводит клавиши в пользовательские окна. Широкая матрица Windows 10,
DPI, IME, accessibility и graphics остаётся непроверенной — см. README.

Встроенные ссылки About/Developer Documentation, installer и команды marketplace
используют https://github.com/MelfisDrake/AgShell.
Для будущего первого публичного релиза требуется новая поставка LICENSE и notices;
прежние частные бинарные assets не публикуются этим исходным снимком.
