# 0007. Живые сессии отложены

Статус: принято, 2026-10-16

## Решение

В первых версиях при перезапуске восстанавливаются раскладка и cwd, по желанию заново запускаются сохранённые команды. Сохранение живых процессов, пока приложение закрыто, откладывается до этапа 6 в roadmap.

## Альтернативы

- **Сразу отдельный процесс-хост**, который владеет ConPTY и шеллами, а окно к нему подключается (как tmux или zmx у agterm). Самая сложная часть проекта, тормозит всё остальное.
- **tmux или zellij внутри WSL-сессий.** Работает уже сейчас без нашего кода, но только для WSL.

## Почему

Сначала нужен работающий терминал с API и статусами, живые сессии — улучшение поверх.
