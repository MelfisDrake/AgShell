# 0008. Установщик: Inno Setup

Статус: принято, 2026-10-16

## Решение

Первый установщик — Inno Setup (обычный `setup.exe`). Позже добавляются winget и подпись кода.

## Альтернативы

- **MSIX.** Подходит для терминалов (так распространяется Windows Terminal), но пакет не установится без подписи доверенным сертификатом, а виртуализация `%APPDATA%` внутри пакета усложняет доступ к конфигам извне. Вернуться к нему вместе с подписью кода.
- **WiX.** Даёт MSI, но сложнее в настройке без явной выгоды на старте.
- **Scoop.** Хорош как дополнительный канал, не как основной.

## Почему

Самый быстрый путь к нормальному установщику. Без подписи кода SmartScreen будет предупреждать при запуске, это решается позже.
