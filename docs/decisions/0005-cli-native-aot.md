# 0005. CLI agshellctl: .NET Native AOT

Статус: принято, 2026-10-16

## Решение

`agshellctl` — отдельный консольный проект на .NET 10, публикуется с Native AOT в один exe без рантайма. Классы протокола общие с приложением.

## Альтернативы

- **Go или Rust.** Тоже дают один маленький exe, но протокол пришлось бы описывать дважды на двух языках.
- **Обычный .NET без AOT.** Медленный старт, а агенты вызывают CLI очень часто.

## Почему

Один язык и общие типы протокола с приложением, быстрый старт, удобная раздача (один файл в `PATH`).

## Последствия

Код, общий с CLI, должен быть совместим с AOT: без рефлексии, сериализация JSON через source generator `System.Text.Json`.
