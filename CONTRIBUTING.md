# Contributing

English | [Русский](CONTRIBUTING.ru.md)

AgShell is experimental. Bug reports and small, focused fixes are welcome; discuss larger behavior or architecture changes first. Review and support are best effort, with no response deadline.

## Bugs

Use the [bug report template](https://github.com/MelfisDrake/AgShell/issues/new/choose). Include the AgShell version and installer/portable source, Windows version, shell, steps, expected and actual results. For visual/input problems include DPI, display layout, keyboard layout and IME. Start with a minimal reproduction in a separate state directory if practical; preserve your normal state.

Share only sanitized logs and screenshots. Remove credentials, terminal output unrelated to the bug, private paths, hostnames, session/thread identifiers and personal messages. Report suspected vulnerabilities according to [SECURITY.md](SECURITY.md), not in a public issue.

## Changes

Read [AGENTS.md](AGENTS.md), build instructions and relevant decisions. Keep changes focused and update both language copies of user documentation. Run the checks relevant to the change and state what was not tested. Preserve third-party attribution. AgShell's own contributions are licensed under [MIT](LICENSE), Copyright (c) 2026 MelfisDrake.
